A personal record of which real time strategy games run on Apple Silicon Macs, plotted route by route: native Mac ports, Parallels, CrossOver, box64, cloud gaming, and the Xbox detour. The entries are the author's own notes, preserved as written.

The native column

Works great: OpenRA and Warzone 2100 both run as native Mac ports, no translation layer involved. Tempest Rising is recorded as fantastic on macOS.

The Parallels column

Plays great: Red Alert 3 inside Parallels, and possibly great on CrossOver as well. Zero-K is playable through box64 on Ubuntu arm64 under Parallels, with the rider that it runs without visual effects.

The blocked corner

Does not work: Beyond All Reason does not work through box64 and requires cloud gaming instead. Company of Heroes 3 refuses every route tried; its AppleGamingWiki page is the linked reference. The record's wider rule: RTS games that do not work on macOS and are not on Xbox Game Pass are a lost cause.

The console detour

Halo Wars Definitive Edition is preferred on Xbox, Halo Wars 2 runs on Xbox, and Age of Empires IV is played on Xbox; all three are on Game Pass. The author's standing advice in the record: for modern games with kernel-level anticheat, play on console and stay sane.

Field notes

Two lines the record keeps coming back to: hardware outweighs the operating system underneath, mattering more than an optimized x86_64 Linux such as CachyOS or Garuda Linux; and Mac gaming gets better every day. The AppleGamingWiki stands as the reference shelf for routes not yet plotted. Xbox Game Pass Ultimate is recorded as the best deal in gaming.
